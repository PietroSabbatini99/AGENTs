          Settings

          Configure your LLM backend. Defaults to a local Ollama instance. Settings are stored in your workspace's config.json and never leave this machine.

          Local setup (Ollama)

          Install Ollama, then run ollama pull qwen3.5:4b and ollama serve. The defaults above will work out of the box.

          Remote providers

          Point the Base URL at any OpenAI-compatible endpoint (OpenAI, Together, Groq, vLLM, LM Studio, etc.) and paste the corresponding API key and model name.
